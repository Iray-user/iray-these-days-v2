# iray,thesedays — SDD v1.1 website

Open `index.html` directly in a browser. No build step or server is required.

Files:
- index.html — Home
- life.html — Life archive
- works.html — Works editorial portfolio
- things.html — Things I Love + front-end cart
- css/style.css — design system, layout, responsive rules, animation
- js/content.js — structured content data
- js/main.js — navigation, Works filtering, cart, reveal animation
- assets/images/ — AI-generated editorial photography, organised by page
- assets/ASSET-MANIFEST.md — visual direction and image inventory

The site follows the supplied SDD v1.1 direction: Editorial × Lifestyle × Personal Archive, distinct layouts per section, semantic HTML, external CSS/JS, CSS variables, responsive reflow, keyboard-accessible interactions, alt text, reduced-motion support, and front-end-only cart behavior.
