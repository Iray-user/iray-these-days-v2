# iray,thesedays Asset Manifest

## Shared visual direction

Quiet, editorial, observational lifestyle photography: natural window light, warm-neutral low-saturation grading, ivory / cream / light wood / muted green / soft black palette, tactile paper-linen-ceramic textures, restrained 35mm grain, soft contrast and gently imperfect compositions. Never use stock-photo posing, glossy commercial lighting, illustration, 3D render, logos, watermarks, or readable generated text.
